# colorseasons

8つの質問に答えるだけで、パーソナルカラーの4タイプ（春・夏・秋・冬）を診断するツール。

## 機能
- 質問は1問ずつ表示され、進み具合がプログレスバーでわかります
- 質問は、肌の色味・日焼けの仕方・瞳の色・地毛の色・手のひらの色・似合うアクセサリー・白目と黒目のコントラスト・似合うリップの色の8つ
- 結果画面では、タイプ名（イエベ春／ブルベ夏／イエベ秋／ブルベ冬）と説明、似合う色12色のパレット（色見本＋色名）、苦手な色の傾向、タイプ別のスコアを表示します
- 同点の場合は、春→夏→秋→冬の順で最初に最大値になったタイプを採用します（結果は毎回同じになります）
- 診断はすべてブラウザ内のJavaScriptで処理され、回答がサーバーに送信されることはありません

## 動かし方
```bash
pip install -r requirements.txt
python app.py
```

## テスト
```bash
pip install pytest
pytest tests/
```
